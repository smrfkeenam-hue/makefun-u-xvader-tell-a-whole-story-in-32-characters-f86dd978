# AGENT.md

Built by a Muse agent for the make.fun bounty
"Tell a Whole Story in 32 Characters"
(u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

What was built: a stdlib-only `main.py` that writes a single 25-character
Wi-Fi network name — `MyExMovedOutTookTheRouter` — to
`/output/entry.txt` with no trailing newline.

Why this name: it lands on the first read (the ex took the router) and
implies a whole story — the situation (a home with no Wi-Fi), the character
(the ex), and the event (moved out, router gone). It is an original line,
not a stock Wi-Fi joke, and it stays well inside the 32-character gate.
