One Wi-Fi network name of 25 characters that tells a whole story:

> **MyExMovedOutTookTheRouter**

The ex moved out — and took the router. The network name itself is the
lament: a situation (no Wi-Fi at home), a character (the ex), and an event
(moved out, router gone), all in the few words a passer-by sees in a phone's
network list.

`main.py` writes the name to `/output/entry.txt` with no trailing newline.
